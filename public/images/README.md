# /public/images

Place all site images here. Naming conventions:

| File                    | Purpose                              | Dimensions      |
|-------------------------|--------------------------------------|-----------------|
| og-image.jpg            | Open Graph share image               | 1200 × 630      |
| hero-bg.jpg             | Hero section background              | 1920 × 1080+    |
| hero-construction.jpg   | Hero foreground / feature image      | 960 × 1080      |
| about-team.jpg          | About section team photo             | 1280 × 720      |
| project-*.jpg           | Individual project thumbnails        | 800 × 600       |
| icon-16.png             | Browser favicon (16×16)              | 16 × 16         |
| icon-32.png             | Browser favicon (32×32)              | 32 × 32         |
| icon-192.png            | PWA icon                             | 192 × 192       |
| icon-512.png            | PWA icon                             | 512 × 512       |
| apple-touch-icon.png    | iOS home screen icon                 | 180 × 180       |
| logo.svg                | Brand logo (vector)                  | —               |
| logo-white.svg          | White variant for dark backgrounds   | —               |

All images are served via next/image for automatic optimisation (WebP/AVIF, lazy loading, LQIP).
